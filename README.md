## 功能

记录维修问题并按四栏看板跟踪：**待安排 → 等上门 → 处理中 → 已完成**，数据使用 localStorage 保存。

### 临时上门码

- 租客确认上门日期和时段后，自动生成**六位数字码**（密码学随机，避开当前有效码）。
- **改约**：生成新码，旧码立即失效（留痕，师傅再输旧码提示"已失效"）。
- **取消预约**：码失效，事项回到「待安排」。
- 师傅到场在该事项上输入**当前预约的码**登记开工，码在时段开始至结束后 30 分钟内有效。
  输错格式、过期、太早、旧码或别的事项的码都**只提示、不保存、不改变任何状态**。

### 费用与存档

- 顶部费用统计**只算开工（处理中）或完工（已完成）的单**。
- 完工后事项进入「已完成」存档，存档使用**独立的 localStorage 键**，可单独删除。

### 旧数据

- 旧版（`todo/doing/done` 结构）数据打开后自动迁移：已完成归入存档，其余进入新看板，照常使用。

## 模块划分（分别维护）

| 模块 | 职责 |
| --- | --- |
| `src/services/codes.js` | 码规则：六位码生成、时段、登记窗口与有效期、核验原因 |
| `src/services/workflow.js` | 事项流转：状态机（安排/改约/取消/登记/完工）、费用统计口径 |
| `src/services/archive.js` | 已完成存档：移入、删除 |
| `src/services/storage.js` | 持久化与旧数据迁移（活动数据与存档分键存储） |
| `src/main.js` | 页面渲染与交互 |
